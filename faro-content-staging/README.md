## ¿Qué es este directorio?

`faro-content-staging/` es un paquete de contenido curado y listo para que el agente de VS Code integre en el sitio Angular de Comunidad FARO.

**Contiene:**
- `seleccion-faro.json` — catálogo estructurado con metadatos de fotos, prédicas y series

- `predicas/` — directorio reservado para referencias de video (los videos NO fueron descargados por tamaño)

## 🛠️ Notas técnicas para el desarrollador

### Sobre las fotos WebP

- Todas las imágenes están en `faro-content-staging/fotos/`
- Formato: **WebP** · Calidad: **87** · Máximo lado mayor: **2000 px**
- EXIF de orientación ya aplicado — las imágenes se muestran correctamente sin CSS adicional
- Las fotos con `rotate_applied_cw_90: true` en el JSON ya fueron rotadas durante la conversión
- El `slug` de cada foto es su nombre de archivo sin extensión (usar como `id` en Angular)

### Sobre los videos

- Los videos NO fueron descargados (tamaño: 4–25 GB cada uno)
- Los clips/reels tienen tamaños de 30–380 MB y están en `G:\Mi unidad\02. DOMINGO\2026\CLIPS\`

## Instrucciones para el agente de VS Code

1. Leer `seleccion-faro.json` para obtener metadatos de todas las fotos
2. Copiar las fotos de `faro-content-staging/fotos/` a `src/assets/images/` (u otra ubicación conveniente)
3. **No implementar código Angular** hasta confirmar la estructura visual con el diseñador
4. Los predicadores/títulos marcados como "POR CONFIRMAR" deben resolverse antes de implementar la sección de prédicas
5. Para prédicas: primero subir los videos a YouTube/Vimeo, luego integrar embeds
6. Priorizar las fotos de prioridad 1 para las posiciones más visibles del sitio
