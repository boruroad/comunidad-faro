# Fotografías de Facebook usadas en esta versión

Esta versión utiliza temporalmente fotografías públicas de la página oficial de Comunidad F.A.R.O. mediante el endpoint público de imágenes de Meta.

## Fotografías

1. **Comunidad / congregación**
   - Publicación: https://www.facebook.com/comunidad.FARO/photos/d41d8cd9/1292138319616112/
   - Media ID: `1292138319616112`
   - Uso actual: hero, personas y footer.

2. **Reunión / músicos / iluminación**
   - Publicación: https://www.facebook.com/comunidad.FARO/photos/1409632304533379/
   - Media ID: `1409632304533379`
   - Uso actual: reunión, Pray Night y mensajes.

## Para producción

Para que el sitio sea totalmente independiente de Facebook, descarga las fotografías originales desde la cuenta administradora de FARO y colócalas en `assets/images/`. Luego cambia únicamente las rutas de `photos` en `js/config.js`.

No se utilizaron fotografías de stock ni imágenes de otras organizaciones llamadas FARO.
